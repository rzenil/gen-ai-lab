## Diseño

Dark-mode nativo con composición **Explore**: galería editorial, consola animada, red de agentes en Canvas, filtros por frente y acciones explícitas por proyecto. HTML/CSS/JS vanilla; sin framework ni dependencia de runtime.

Fuente del catálogo: base de conocimientos personal con revisión humana. Los repos que simulan sistemas empresariales son deliberadamente genéricos y no contienen contratos, datos ni secretos de una organización real.
